# SpikiLang (スピキ言語)

**ｽﾋﾟｷｦｲｼﾞﾒﾇﾝﾃﾞ**

Brainfuckベースの言語です。

# Vocabulary

| 語録 | 対応命令 | 内容 |
| :--- | :---: | :--- |
| `ｱ!` | `+` | 現在のセルの値を +1 する |
| `ｳﾜｧｧ!` | `-` | 現在のセルの値を -1 する |
| `ｽﾋﾟｷ!` | `>` | ポインタを右に移動 |
| `ｽﾋﾟｷﾃﾞﾙｼﾞﾊﾞｾﾞﾖ! ` | `<` | ポインタを左に移動 |
| `ｽﾋﾟｷﾓﾘﾁﾊﾞﾀﾞﾝｷﾞｼﾞﾊﾞｾﾞﾖ!` | `.` | 現在の値を文字として出力 |
| `ｽﾋﾟｷｦｲｼﾞﾒﾇﾝﾃﾞ` | `,` | 1文字入力を受け取る（改行スキップ機能付） |
| `ﾁｮﾜﾖｰ` | `[` | ループ開始（値が0ならジャンプ） |
| `ﾁｮﾜﾖｰ!` | `]` | ループ終了（値が非0なら戻る） |
| `ﾁｮﾜﾖｰﾁｮﾜﾖｰﾎﾊﾞｷﾞﾁｮﾜﾖｰ` | `z` | 現在のセルを 0 にリセット |
| `ﾈﾙﾇｲﾛｯﾀﾞｲﾛｯｹﾎﾟﾝﾆｮｸ...` | `p` | 現在の値を **数値** として出力 |
| `ﾃﾞﾙｼﾞﾊﾞｾﾞﾖ!` | `q` | プログラムを終了する |

## 使い方

### 実行
`.ｽﾋﾟｷ!` ファイルを作成し、コンパイラを実行します。
```bash
python spiki_compiler.py your_code.ｽﾋﾟｷ!

spiki_compiler.exe your_code.ｽﾋﾟｷ!
```

### VScodeでシンタックスハイライトをつける
Hilightingの中にある `%USERPROFILE%\.vscode\extensions`直下に`spiki-lang`を置いてください
